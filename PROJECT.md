# Project Metadata / 프로젝트 메타데이터

## Overview / 개요

CMDS Eagle is an Obsidian plugin that connects an Eagle asset library with an Obsidian vault. This repository is a public fork of `johnfkoo951/cmds-eagle`.

CMDS Eagle은 Eagle 자산 라이브러리와 Obsidian vault를 연결하는 Obsidian 플러그인입니다. 이 레포는 `johnfkoo951/cmds-eagle`의 공개 fork입니다.

## Purpose / 목적

- Search an Eagle library from Obsidian.
- Embed, paste, drop, and upload images from notes.
- Support cloud upload and cross-platform path conversion.
- Make the fork's upstream attribution, integration scope, and asset rights clear.

- Obsidian 안에서 Eagle 라이브러리를 검색합니다.
- 노트에 이미지를 임베드하고 붙여넣기/드롭/업로드 흐름을 지원합니다.
- 클라우드 업로드와 Mac/Windows 경로 변환을 지원합니다.
- fork의 upstream 표시, 연동 범위, 자산 권리 범위를 명확히 합니다.
